  - Facilite la découverte
  - Navigation entre services

### Style Unifié :
- ✅ **Couleurs** : Bleu neon (#0f33ff) + gris (#0c0c0c)
- ✅ **Typography** : Montserrat, hiérarchie claire
- ✅ **Responsive** : Mobile-first, optimisé tous appareils
- ✅ **Animations** : Hover effects, transitions fluides

### Composants Récurrents :
- **En-tête de page** : Titre + sous-titre avec gradient
- **Cartes de services** : 6 services par page avec hover
- **Sections** : Structure claire avec titre + underline bleu
- **CTA** : Appel à l'action vers contact/projet

### Structure Répétée :
```
1. En-tête (header avec titre)
2. Section Introduction
3. Section Services (grille de 6 cartes)
4. Section Spécifique (processus/technologies/principes)
5. Section Avantages (6 cartes)
6. CTA Section
7. Footer Navigation
```
