## 🔧 Technologies Utilisées

### Frontend
- **HTML5** - Structure sémantique
- **CSS3** - Animations, gradients, transitions
- **SASS** - Préprocesseur (modular architecture)
- **JavaScript** - jQuery pour slider (existant)

### Méthodes CSS Avancées
- **Gradient Animation** - background-position techniques
- **Keyframes** - 15+ animations personnalisées
- **Cubic-Bezier** - Easing functions avancées
- **Backdrop Filter** - Glassmorphism effect
- **Drop Shadow** - Effets de profondeur
- **Transform** - Scale, rotate, translateX/Y

### Architecture
- **Component-based SASS** - Modules (_intro, _work, _about, etc.)
- **Responsive Design** - Breakpoints: 1180px, 900px, 767px, 600px
- **Dark Theme** - #0c0c0c background, neon blue #0f33ff accents
